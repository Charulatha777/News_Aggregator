\## Git Workflow



1\. Create a feature branch.

2\. Make changes to the required module.

3\. Commit the changes.

4\. Push the feature branch to GitHub.

5\. Create a Pull Request.

6\. Perform code review.

7\. Resolve conflicts if required.

8\. Merge the approved Pull Request into main.



\## Branches



\- main - Stable project branch

\- feature-readme - Documentation module

\- feature-api - API development module

\- feature-docker - Docker module
